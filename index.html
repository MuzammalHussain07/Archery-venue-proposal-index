ARchery — 11-Lane Immersive Archery Venue
Proposal • Deliverables • Timeline • Cost Model

One-line Summary

Deliver a production-grade, local-LAN, 11-lane ARchery system: lane apps (macOS/Unity), BLE bow support, impact detection, LED control, iPad UI, and a staff Hub. Full IP transfer (source + exclusive rights).

Deliverables (What you will get)

  • 11 Lane Apps — macOS builds (Apple Silicon), Unity project, lane config, lane-side web server for iPad UI.
  • Hub App — macOS app (Tile dashboard, session control, logging, local DB).
  • BLE Bow Module — macOS BLE manager, protocol docs, sample firmware handshake, SOS triple-press handling.
  • Hit Detection Pipeline — Arduino/USB piezo input, camera frame matching, calibration tool (projector→camera mapping).
  • LED Control — WLED/UDP controller library, sample FX sequences, mapping to lane events.
  • Game Engine — 10 light-weight Unity games (2D/2.5D), assets, difficulty scaling, 1080p@120Hz output presets.
  • iPad UI — Local HTML/JS served by each lane; game select, difficulty, help request.
  • Docs & Deployment — Install guide, calibration guide, runbooks, hardware wiring, test plans.
  • Source & IP — Full repo with build scripts, CI, and exclusive IP transfer upon final payment.
  • QA & Handover — 2-week on-site/remote acceptance, bug-fix window, staff training videos.

Tech Plan (Summary)

Lane (Runtime)

  • Unity (LTS) for games & UI overlay
  • macOS native wrapper for USB and BLE (Swift helper + Unity plugin)
  • Local web server (lightweight Node/Express) serving iPad UI
  • OpenCV for camera-frame processing (Native plugin or separate process)

Hub

  • macOS app (Electron + native helper) or native Swift app
  • Local DB: SQLite for quick install or Postgres for larger installs
  • LAN discovery via mDNS/UDP, secure token per lane

Core Pipelines

  1. Hit detection: Piezo → USB serial event → timestamp → match nearest camera frame → compute XY → map to game coordinates.
  2. BLE Bow: Bond + persistent connections (6 bows/slot), active-bow gating, triple-press SOS to Hub.
  3. LED: WLED over UDP/HTTP; lane events trigger FX playlists.

Milestones & Timeline (4 months)

  • Month 1: Architecture, prototypes for BLE, USB sensors, camera capture, simple game.
  • Month 2: Full lane pipeline proof (camera→hit mapping), basic Unity game-play loop, iPad UI prototype.
  • Month 3: 5 games, robust BLE handling, LED integration, Hub basic controls.
  • Month 4: Remaining games, QA/performance, deployment scripts, staff training & handover.
